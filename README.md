# controle-financeiro-familiar

Plugin de listagem do **Livro financeiro da família**, app de lançamentos, contas a vencer e conciliação de um casal.

- Site: https://controle-financeiro.mfotrust.com
- Licença: MIT (ver `LICENSE`)

Este pacote só declara o manifesto e o ícone. Não traz skills, comandos, hooks, agentes nem servidores MCP, e não contém código do app.
